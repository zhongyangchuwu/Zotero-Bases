# Zotero Bases 使用指南

## 打开和整理表格

1. 从 Zotero 主窗口选择 **工具 → Zotero Bases**。再次选择会聚焦已有工作区。双屏阅读时，用右上角的 **在新窗口打开** 移出当前视图，也可把独立窗口设为默认。
2. 选定范围后，用 **列** 或表头最右侧的 `+` 切换字段、调整顺序或恢复默认列序。悬停某行或聚焦标题格时，点 **打开** 定位原条目；有 PDF 附件时点旁边的 **PDF** 直接打开阅读器。双击行也可打开 PDF（没有 PDF 时定位条目）。
3. 用视图标签切换，点 `+` 新建，点 `⋯` 打开视图设置、复制、改名或删除。视图会记住范围、列顺序、筛选、排序、分组、行密度和列宽。

默认使用紧凑单行，可切换 **标准** 或 **展开换行**。三种密度都可滚动浏览全部结果，底部显示匹配与选中数量。悬停可查看完整作者、标签或时间。按 `/` 聚焦搜索；搜索覆盖当前范围内全部条目，包括尚未滚到的行。标题、作者、年份、来源、标签、引用关键词、DOI、刊名简称、出版社和所属分类始终参与搜索，其他可见列也会参与。搜索与已保存筛选同时生效，不写进视图。

独立窗口较窄时，搜索框会收成放大镜。点击图标或按 `/` 展开；收起搜索框不会清除当前搜索。

### 选择文献列

**列** 浮层按「常用列」「自定义属性」「更多 Zotero 列」分组。可用中文名、英文名或字段键查找；输入关键词会展开命中的分组。按 `Esc` 先清空列搜索，再按一次关闭浮层。勾选后即时显示，可用上下箭头调整列在表格中的位置。

- **常用列**：默认八列之外，还可添加引用关键词、所属分类、完整日期、修改日期、最后阅读时间、笔记数、附件数、DOI、网址、刊名简称、出版社和短标题。
- **更多 Zotero 列**：默认折叠，包含卷次、期号、页码、语言、系列、系列标题、索书号、地点、版次、访问时间、档案、档案编号和版权。

条目缺失或不支持的字段留白；笔记数、附件数为零时也留白，但仍可按零筛选。最后阅读时间取未删除附件中最新的阅读记录。点击 DOI 或网址可在外部浏览器打开；悬停或聚焦 DOI 格可复制 DOI。

**PDF** 列显示 Zotero 的主附件图标：红色 PDF、EPUB、网页快照或其他文件。点击图标交给 Zotero 打开。此列原有的排序和筛选仍按「是否有 PDF」计算。

左键点表头打开列菜单，可设为主排序、追加为次级排序、左右移动、隐藏该列或恢复默认列宽。直接拖动表头也能换列，以插入线为准；只拖右侧手柄才会调宽，双击手柄可复位。隐藏列至少保留一列；恢复默认列序不会重新显示已隐藏的列。

在 **排序** 中添加、删除或调整排序规则，修改即时生效，浮层保持打开。上方规则优先，值相同才看下一条；空值始终在末尾。多个规则生效时，表头的 `↑1`、`↓2` 同时表示方向和优先级。排序、筛选和分组按钮显示正在使用的规则数。按 `Esc` 先收起已展开的下拉菜单，再按一次关闭浮层并返回触发位置，不清空搜索或选区。

多个筛选条件须同时满足。数值列可比较大小，日期列按日比较，分类按所选名称判断属于或不属于。属性、选项、标签或分类不再存在时，Bases 会跳过相应条件并提示，可一键移除失效规则。

**分组** 可按年份、类型、计数、单选属性或复选框归类。日期按月分组，空值放在最后的「未设置」。按标签或分类分组时，先选一个值，条目只进入「属于」或「不属于」其中一组；同时归属多个分类也不会重复显示。点组头可折叠或展开。分组字段失效时，仍显示未分组的表格。

### 标签配色

点 **标签** 表头 → **标签配色**，选择 **精确标签** 或 **标签前缀**，输入名称（例如 `topic/`），再点色点，即时应用。Zotero 已设色的标签优先，其次是精确标签、最长匹配前缀；没有匹配就显示灰色。选「恢复继承颜色」可移除当前规则。Bases 的规则不占 Zotero 的彩色标签名额。

## 全局设置

打开 Zotero **设置 → Zotero Bases**，或点工作区右上角的 **⚙**。设置即时保存，已打开的工作区无需关闭。默认打开方式只影响尚未打开的工作区；新建视图默认密度不改已有视图。作者列可切换 `et al.` 或单行截断，两种模式都保留完整作者的悬停提示与搜索。

- **Classic**：默认，沿用 Zotero 原生表格风格。
- **Terminal**：直角、细分隔线与等宽元信息；浅色底为 `#f8fafc`。
- **Modern**：柔和圆角与留白。

三套外观都跟随 Zotero 的明暗模式、界面字体和字号。用 Zotero 的 **视图 → 字体大小** 调整字号，Bases 标签页和独立窗口的表格会随之调整行高，无需重开。界面语言可跟随 Zotero，或固定为简体中文 / English；表格键盘流和底部快捷键提示可在全局设置中关闭。

### 自定义 CSS

CSS 只作用于 `.zb-workspace` 和其中的元素，不影响 Zotero 原生界面或 PDF。可用 `--zb-font-family` 和 `--zb-font-size` 覆盖跟随 Zotero 的字体和字号。其他常用变量：`--zb-bg` 背景、`--zb-surface` 控件表面、`--zb-text` 正文、`--zb-muted` 次要文字、`--zb-border` 边框、`--zb-accent` 强调色、`--zb-link` DOI 与网址链接色、`--zb-selected` 选区、`--zb-danger` 错误、`--zb-row-height` 行高。常用类：`.zb-top`、`.zb-toolbar`、`.zb-table-wrap`、`.zb-cell-pill`、`.zb-editor`、`.zb-table-status`。

```css
.zb-workspace {
  --zb-accent: #8b5cf6;
}
```

支持普通选择器、`@media` 和 `@supports`。不支持伪元素、嵌套样式规则和 `@import`、`@font-face`、`@keyframes` 等全局规则。

### JSON 备份

在设置的 **同步与备份** 中导出或导入 JSON。导入会替换属性定义和视图，以及备份中包含的 Bases 标签配色；不含标签配色的旧备份会保留现有规则。导入立即生效，不修改全局外观设置、Zotero 原生标签配色或条目的 `Extra`。文件无效时不会写入配置。

## 表格键盘操作

先用 `Tab` 进入表格，或点击单元格。焦点在顶部视图标签时，左右方向键仍用于切换视图。

| 键位                                                   | 操作                                                       |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| `h` / `j` / `k` / `l`、方向键                          | 左 / 下 / 上 / 右移动；组头上按 `h` 折叠、`l` 展开         |
| `gg` / `G`                                             | 跳至首行 / 末行                                            |
| `PageUp` / `PageDown`、`Ctrl+u` / `Ctrl+d`             | 向上 / 向下滚动一个视口                                    |
| `Enter` / `i`                                          | 编辑属性；在标题列定位 Zotero 条目；在组头切换折展         |
| `x`、`Shift+j` / `Shift+k`（或 `Shift+↓` / `Shift+↑`） | 切换当前行勾选、向下 / 向上延展选区；表格不占用裸空格键    |
| `o`                                                    | 从当前行直接打开 PDF 阅读器                                |
| `/`、`Esc`                                             | 聚焦搜索；`Esc` 优先关闭浮层或退出编辑，然后才清空搜索或选区 |

## 批量编辑

勾选行，或用 `Shift` + 点击单元格或勾选框跨视口选择一段；表头复选框选中当前筛选匹配的所有条目，包括视口外和折叠组里的条目。在 **批量编辑** 中选择属性并设置或清空值，也可添加、移除原生标签。提交即写入，不需再次确认；只读或更新失败的条目会跳过，并汇总更新与跳过数量。

## 定义和编辑属性

在属性管理中选类型并添加属性，再在 **列** 中显示它。点击单元格或按 `Enter` 编辑；复选框直接切换；单选/多选可用方向键选择选项、用 `Enter` 即时保存。文本与数值按 `Enter`、离开输入框或滚动到编辑行被回收时保存；按 `Esc` 放弃未提交的输入并返回原单元格。可直接清空属性。点击标签单元格可添加已有或新标签，也可移除标签。只读文库可查看，不能编辑。

属性值是 Zotero 条目 `Extra` 中的文本，例如：

```text
Project: Reading log
Score: 4.5
Reviewed: true
ReviewState: Reading
Method: Transformer; Diffusion
```

取消勾选复选框或清空属性会移除对应行。更新属性时，同名的重复行收为一行，其他内容不改。输入 `Status`、`DOI` 等保留键时，表单会在行内提示，并可一键采用建议名称，例如 `Reading Status`。

重命名单选或多选选项会更新可写条目中的旧名称；无法修改的条目会计入跳过结果。删除属性或选项时可以只移除定义（保留旧值），或一起清理条目中的值。选项名不能含分号。

在 **属性** 中可给单选、多选的每个选项点选 8 色圆点。也可打开单元格编辑器，点选项旁的色点换色，不会改变此条目的选中值。选「自动配色」会恢复按名称生成的颜色。颜色即时更新，随属性定义进入文库同步和 JSON 备份，不改条目的 `Extra`。

卸载插件不会删除 `Extra` 中的属性值。Bases 不读取或迁移 Zotero Neo 的设置或旧选项格式。

## 在设备之间同步配置

1. 确认 Zotero 已登录同一个账号，并为「我的文库」开启附件文件同步。然后在 Bases 设置的 **同步与配置备份** 中开启文库同步。不必填写密钥或先选位置。同步开启后，工作区右上角的状态点可查看状态并返回设置。
2. 配置写入「我的文库」中 `[Zotero Bases] Sync — Do Not Delete` 条目的 JSON 附件，再由 Zotero 同步。请勿删除该条目或附件。可在同一设置区通过 **更改位置与名称** 移动或改名。
3. 属性定义和已保存视图变动后会自动更新附件，也可点 **立即同步**。在另一台设备启用后，如文库版本与本机不同，选 **应用云端定义与视图** 或 **以本机为准覆盖云端**。应用云端前会保留一份本机配置，可在同一设置区恢复。

同步附件只含属性定义和视图，不含 Bases 标签配色、文献列表或条目属性值。属性值仍由 Zotero 随条目的 `Extra` 同步。使用新版选项颜色前，请先把参与同步的设备都升级到 0.4.2 或更新版本。

## 供其他插件调用

```ts
Zotero.ZoteroBases?.api.version; // 1
await Zotero.ZoteroBases?.api.open({ window, mode: 'default' });
```

`open(options?: { window?: Window; mode?: 'default' | 'tab' | 'window' }): Promise<void>`。若已有工作区，优先聚焦；否则按指定模式打开。省略模式或用 `default` 时遵循全局设置。省略窗口时使用当前 Zotero 主窗口。插件停用或卸载后入口会移除。
