# Zotero Bases 使用指南

## 打开和整理表格

1. 从 Zotero 主窗口选择 **工具 → Zotero Bases**。再次选择会切回已有标签页。双屏阅读时，用右上角的 **在新窗口打开** 移出当前视图。
2. 切换全部文库、某个文库或分类。在列控件中选择要显示的原生字段与自定义属性；按一列升序或降序。点标题定位原条目，双击行优先打开其 PDF，没有 PDF 时定位条目。
3. 通过表格上方的视图栏新建或切换视图。当前视图会立即记住范围、列、筛选和排序。可以改名、删除或另存为另一视图。

多个筛选条件须同时满足。选择的属性、选项或标签不再存在时，Bases 会跳过对应条件并提示，可以一键移除它们；有效条件仍然生效。

## 定义和编辑属性

在属性管理中选类型并添加属性，再在 **列** 中显示它。点击单元格或按 `Enter` 编辑；复选框直接切换，单选/多选点选即保存，文本与数值按 `Enter` 或离开输入框保存。可直接清空属性。点击标签单元格可添加已有或新标签，也可移除标签。只读文库可查看，不能编辑。

属性值是 Zotero 条目 `Extra` 中的文本，例如：

```text
Project: Reading log
Score: 4.5
Reviewed: true
ReviewState: Reading
Method: Transformer; Diffusion
```

取消勾选复选框或清空属性会移除对应行。更新属性时，同名的重复行收为一行，其他内容不改。Zotero、CSL 和 Better BibTeX 的保留键（如 `Status`、`DOI`、`Citation Key`）不能用来创建自定义属性。

重命名单选或多选选项会更新可写条目中的旧名称；无法修改的条目会计入跳过结果。删除属性或选项时可以只移除定义（保留旧值），或一起清理条目中的值。选项名不能含分号。

`Extra` 随 Zotero 条目同步；属性定义和视图仅在当前 Zotero 配置中保存。卸载插件不会删除条目中的属性值。Bases 不读取或迁移 Zotero Neo 的设置或旧选项格式。
