# Zotero Bases 使用指南

## 打开和整理表格

1. 从 Zotero 主窗口选择 **工具 → Zotero Bases**。再次选择会切回已有标签页。双屏阅读时，用右上角的 **在新窗口打开** 移出当前视图。
2. 选定范围后，用 **列** 控制显示字段，点表头切换升降序。点击标题定位原条目；点 PDF 徽标直接打开阅读器，双击行也可打开 PDF（没有 PDF 时定位条目）。
3. 用视图标签切换，点 `+` 新建，点 `⋯` 打开视图设置、复制、改名或删除。视图会记住范围、列、筛选、排序、分组、行密度和列宽。拖动表头分隔线调宽，双击分隔线恢复默认宽度。数值列按数值排序，空值始终在末尾。

默认使用紧凑单行，可切换 **标准** 或 **展开换行**。悬停可查看完整作者、标签或时间。按 `/` 聚焦搜索，按 `Esc` 清空。搜索覆盖当前范围的所有分页，匹配标题、完整作者、来源、年份、标签和可见自定义属性；它与已保存筛选同时生效，不写进视图。

多个筛选条件须同时满足。选择的属性、选项或标签不再存在时，Bases 会跳过对应条件并提示，可以一键移除它们；有效条件仍然生效。

在 **分组** 中选择单选属性、复选框、年份、条目类型或某个 Zotero 标签。标签按是否包含该标签分组；空值放在末尾的「未设置」。点击组头可折叠或展开；分组字段失效时仍会显示未分组的表格，并提示清除分组。

## 批量编辑

勾选行，或用 `Shift` + 点击选一段；表头复选框选中当前筛选匹配的所有条目，包括其他页和折叠的组。在 **批量编辑** 中选择属性并设置或清空值，也可添加、移除原生标签。提交即写入，不需再次确认；只读或更新失败的条目会跳过，并汇总更新与跳过数量。

## 定义和编辑属性

在属性管理中选类型并添加属性，再在 **列** 中显示它。点击单元格或按 `Enter` 编辑；复选框直接切换，单选/多选点选即保存，文本与数值按 `Enter` 或离开输入框保存。可直接清空属性。点击标签单元格可添加已有或新标签，也可移除标签。只读文库可查看，不能编辑。

属性值是 Zotero 条目 `Extra` 中的文本，例如：

```text
Project: Reading log
Score: 4.5
Reviewed: true
ReviewState: Reading
Method: Transformer; Diffusion
```

取消勾选复选框或清空属性会移除对应行。更新属性时，同名的重复行收为一行，其他内容不改。输入 `Status`、`DOI` 等保留键时，表单会在行内提示，并可一键采用建议名称，例如 `Reading Status`。

重命名单选或多选选项会更新可写条目中的旧名称；无法修改的条目会计入跳过结果。删除属性或选项时可以只移除定义（保留旧值），或一起清理条目中的值。选项名不能含分号。

卸载插件不会删除 `Extra` 中的属性值。Bases 不读取或迁移 Zotero Neo 的设置或旧选项格式。

## 在设备之间同步配置

1. 确认 Zotero 已登录同一个账号，并为「我的文库」开启附件文件同步。然后在 Bases 右上角点 **开启文库同步**。不必填写密钥或先选位置。
2. 配置写入「我的文库」中 `[Zotero Bases] Sync — Do Not Delete` 条目的 JSON 附件，再由 Zotero 同步。请勿删除该条目或附件。可以在同步菜单的 **更改位置与名称** 移动或改名。
3. 属性定义和已保存视图变动后会自动更新附件，也可点 **立即同步**。在另一台设备启用后，如文库版本与本机不同，选 **应用云端定义与视图** 或 **以本机为准覆盖云端**。应用云端前会保留一份本机配置，可从同步菜单恢复。

同步附件只含属性定义和视图，不含文献列表或条目属性值。属性值仍由 Zotero 随条目的 `Extra` 同步。同步未启用时，定义和视图只保存在本机。
